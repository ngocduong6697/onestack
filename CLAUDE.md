# OneStack

## Mission

Build a reliable operating system for a one-person company.

## Stack

Frontend:

- Next.js
- React
- TypeScript
- Tailwind

Backend:

- Node.js
- PostgreSQL

AI:

- Claude
- Gemini
- OpenAI

Infrastructure:

- Docker
- Nginx
- AWS

## Engineering Principles

- Clean Code
- SOLID
- DRY
- KISS
- YAGNI
- Strong typing
- Small modules
- Explicit dependencies
- No unnecessary abstractions

## Rules

1. Never modify architecture without approval.
2. Never introduce a dependency without justification.
3. Never duplicate business logic.
4. Never put business logic inside UI components.
5. Never expose secrets to frontend.
6. Every API must have validation.
7. Every important action must be auditable.
8. Every AI request must record usage and cost.
9. Every database migration must be reversible when possible.
10. Every feature must have tests.
