# OneStack Roadmap

Build order for the operating system of a one-person company. Phases are
sequential; a phase is done when every item in it is shipped, tested, and
auditable per [CLAUDE.md](../CLAUDE.md).

## Phase 0 — Foundation

- Repository
- CLAUDE.md
- Architecture
- CI/CD
- Docker
- Environment
- Database
- Logging
- Error handling

## Phase 1 — Core

- Auth
- User
- Organization
- Workspace
- Roles
- Permissions

## Phase 2 — Business

- CRM
- Leads
- Customers
- Products
- Subscriptions
- Billing

## Phase 3 — AI

- AI providers
- Models
- Agents
- Prompts
- Tools
- Conversations
- Usage
- Cost tracking

## Phase 4 — Automation

- Workflows
- Triggers
- Actions
- Jobs
- Webhooks
- Schedules

## Phase 5 — Intelligence

- Analytics
- Business dashboard
- AI cost dashboard
- Revenue dashboard
- Customer analytics
- Product analytics

## Phase 6 — Production

- Security
- Rate limiting
- Backup
- Monitoring
- Alerts
- Observability
- Disaster recovery
